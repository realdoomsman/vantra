# VANTRA — brand kit

Molten orange on graphite. Swiss editorial.

The mark is a **burn-down**: six rules narrowing to a point — a treasury spending itself
until the agent dies. Read top-down it is a depletion chart; read as a silhouette it is a **V**.
Bone at the top (full treasury), graphite through the middle, molten at the tail (the money
running out). Never recolour the ramp; it is the whole idea.

## Palette

| token | hex | use |
|---|---|---|
| `ink` | `#0B0B0D` | page ground, the only background |
| `panel` | `#141519` | raised surface |
| `line` | `#26282E` | hairline rules, borders |
| `bone` | `#EDE9E3` | primary text, top bar of the mark |
| `dim` | `#6E7178` | secondary text, spent rules |
| `molten` | `#FF5A1F` | the one accent — signal, never decoration |
| `ember` | `#FF8A3D` | the tail rule only |
| `deep` | `#C63C0A` | accent on light ground |

Green and red appear **only** for alive/dead and P&L. Nothing else gets a colour.

## Rules

- Clear space around any lockup = the height of one bar of the mark.
- The wordmark is always tracked wide (`+0.16em` equivalent) and always all caps.
- Never stack the mark and wordmark horizontally at under 120px wide — use the mark alone.
- Never put the mark on a mid-tone. Ink or molten, nothing between.
