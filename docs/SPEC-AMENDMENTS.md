## A. LLM interfaces & providers (§6, §8.1)
1. `LlmContent` gains `{ type:'thinking'; thinking: string; signature: string }` and `{ type:'redacted_thinking'; data: string }`. Anthropic provider maps these 1:1 both ways; the step loop replays `res.content` verbatim (never filters). OpenAI/OpenRouter providers drop them on outbound mapping. Persist in `steps.transcript`; strip from every public API/WS payload.
2. `LlmRequest` gains `toolChoice?: 'auto' | 'none'` (default auto), `signal?: AbortSignal`, and `maxTokens` default **16000**. Closing/"last words" completions send the SAME tools with `toolChoice:'none'` (never `tools: []`).
3. `LlmResponse.stopReason: 'end_turn'|'tool_use'|'max_tokens'|'refusal'|'pause_turn'|'stop_sequence'|'error'` + `stopDetails?: { category: string | null; explanation?: string }`.
4. `ModelInfo` gains `thinking: 'adaptive' | 'budget' | 'none'` and `cacheWritePerM?: number` (default `inputPerM × 1.25`); `cacheReadPerM` defaults `inputPerM × 0.1`. Catalog: claude-opus-5 / claude-sonnet-5 → adaptive, supportsEffort true; **claude-haiku-4-5 → thinking 'none', supportsEffort false** (never send `thinking` or `output_config.effort` to it). OpenAI gpt-5.x → thinking 'none', supportsEffort true (maps to `reasoning_effort`: low→low, medium→medium, high/xhigh/max→high). OpenRouter models: thinking 'none', supportsEffort false.
5. Shared `priceUsage(model, usage): Micro = ceil(in×inputPerM + cacheWrite×cacheWritePerM + cacheRead×cacheReadPerM + out×outputPerM) / 1e6 × 1e6` (prices per 1M tokens → micro-dollars). Anthropic: `inputTokens=usage.input_tokens, cacheReadTokens=cache_read_input_tokens, cacheWriteTokens=cache_creation_input_tokens`. OpenAI: `inputTokens = prompt_tokens − cached_tokens`, `cacheReadTokens = cached_tokens`, `outputTokens = completion_tokens`. OpenRouter: send `usage: { include: true }`; `costMicro = ceil(usage.cost × 1e6)` when present else priceUsage; boot refresh `inputPerM = Number(pricing.prompt) × 1e6`.
6. Anthropic request shape: `system: [{ type:'text', text, cache_control:{ type:'ephemeral', ttl:'1h' } }]`; tools sorted by name, each `strict: true`; top-level `cache_control: { type:'ephemeral' }` (auto-caches the conversation tail); `thinking: { type:'adaptive' }` only for adaptive models; `output_config: { effort }` only if `supportsEffort`; SDK client `maxRetries: 0`, per-request `{ signal, timeout: min(remainingStepMs, 300000) }`; the ROUTER owns retries (3× on 429/5xx/network, identical body). Parse tool inputs with JSON (never string-match). Never use assistant prefill.
7. OpenAI/OpenRouter mapping: assistant `tool_use` → `tool_calls[{ id, type:'function', function:{ name, arguments: JSON.stringify(input) } }]`; each `tool_result` → its own `{ role:'tool', tool_call_id, content }` message immediately after the assistant message (isError → content prefixed `ERROR: `). `finish_reason` stop→end_turn, tool_calls→tool_use, length→max_tokens, content_filter→refusal. Send `max_completion_tokens`, `parallel_tool_calls: true`. OpenAI strict mode: registry keeps ONE canonical schema (Anthropic style, `additionalProperties:false`); the OpenAI provider transforms optional properties into `required` with `type: [T, 'null']`; executors treat `null` as absent. Unit test: every registry tool passes both validators.
8. System prompt is a pure function of (agent identity, directive, enabled tools, sorted catalog with fixed 4-decimal prices, walletPubkey, cluster, usdcMint, profileUrl). No balances, timestamps or step numbers in it — those live in STATUS.
9. `set_model` / `set_effort` write `agents.model/effort` but the RUNNING step keeps its resolved model/effort; tool result says "takes effect next heartbeat".

## B. Step loop, budget, rent, burn (§8.5, §8.6, §8.11)
10. Pre-flight before EVERY completion: `ctxTokens` = previous usage (in+cacheRead+cacheWrite+out) + ceil(newToolResultChars/4) (round 1: ceil(chars(system+tools+STATUS)/4)); `est = estimateMicro(model, ctxTokens, maxTokens)`; `budgetLeft = min(treasury, MAX_STEP_COST − STEP_SUMMARY_RESERVE_MICRO(50_000) − stepCost)`; if `est > budgetLeft` shrink `maxTokens = clamp(floor((budgetLeft − inputEstMicro) / outputPerM × 1e6), 1024, 16000)`; if it cannot reach 1024 and rounds > 0 → closing completion; if rounds == 0 → die('insolvent'). The closing completion (`toolChoice:'none'`, maxTokens 1024) always runs from the reserve, even after a cap abort. If treasury < 0 after any post → `die('insolvent')` at END of this step.
11. Stop handling: `pause_turn` → push assistant content and continue with no user message (counts as a round). `max_tokens` with a tool_use present → drop that partial assistant turn, retry once with `maxTokens = min(2×, 16000)` if budget allows, else status 'aborted' error 'max_tokens'. `refusal` → never execute that turn's tools, status 'refused', `steps.error = category`, no further rounds. Store `stopReason` on steps.
12. Step timeout: `STEP_TIMEOUT_MS` drives an AbortController passed as `signal`; tool timeouts capped by remaining step time. On abort: no ledger post for the aborted call, step 'aborted', error 'timeout'. Already-posted rounds stand.
13. Rent: add `'rent'` to `LedgerKind` and `spendRentMicro` to AgentPublic/GlobalStats (`compute` = bash/service CPU only). `chargeRent(agent, until)` bills `[last_rent_at, until)` at the rate of the status held over that interval; called at step acquire, end of step (before status transitions), inside pause/unpause/terminate/revive/sleep, and from an hourly job for agents whose next step is > 1h away. Paused agents: `sandbox.stop` and sleep rate. Death order: `treasury <= 0 → die('rent')` THEN `treasury < minStep → die('insolvent')`.
14. `cheapest()` = enabled model minimising `estimateMicro(m, 3000, 600)`. `minStep = estimateMicro(cheapest, 6000, 1000) + rent for one heartbeat + hosting for one heartbeat`. If `treasury < 3 × minStep` → "last-words mode": cheapest model, `toolChoice:'none'`, maxTokens 600, STATUS says it is about to die, then `die('insolvent')` after the step.
15. Burn: `projectedBurn = rentPerDay(status) + hostingPerDay + stepsPerDay × avgStepCost` where `stepsPerDay = 1440 / heartbeat_min` (or 1440 / sleepMinutes while sleeping), `avgStepCost` = mean of last ≤20 step costs or `estimateMicro(model, 6000, 1500)` when none. `trailingBurn = spend over min(age, 7d) ÷ min(ageDays, 7)` with ageDays a float floored at 1/24. `burnPerDayMicro = ageDays < 1 ? projected : trailing`; `AgentPublic.burnBasis: 'projected' | 'trailing'`. Spawn page uses projectedBurn with the chosen model/heartbeat. `ageDays = ((diedAt ?? now) − bornAt)/86400000` (1 decimal).
16. Context carry-over in STATUS (zero tool cost, cap STATUS at 8k chars): `/work` file tree (depth 2, ≤1.5k chars), contents of `/work/NOTES.md` if present (≤4k chars; system prompt tells the agent to keep its plan there), last 3 step summaries with stop status, last step's tool-call names with error flags, `walletPubkey, cluster, usdcMint, profileUrl, siteUrl (or null), services: [{id,name,priceUsd,endpointUrl,calls,revenueUsd}]`, new deposits, owner messages, unsettled, `aboutToDie: boolean`.
17. Mock provider usage: `inputTokens = ceil(chars(system+tools+messages)/4)`; round ≥2: `cacheReadTokens` = previous total input, `inputTokens` = new tokens only; round 1: `cacheWriteTokens = inputTokens`; `outputTokens = ceil(chars(response)/4) + thinkingSim(effort)` (low 200 … max 2500); `costMicro = priceUsage(model, usage)`; honours `maxTokens` and `toolChoice:'none'`. Demo "spender" archetype runs 8 rounds with 12k-char bash outputs so the cap path fires.
18. `steps` / `StepPublic` add `cacheWriteTokens`, `rounds`, `stopReason`; token/cost fields are sums over rounds. `StepPublic.status` adds `'running'`.
19. `TOOL_COST_MICRO.service_call_min` is the SELLER's compute floor per handler run (`max(500, cpuMs × 0.1)`); the buyer pays only `payment` = price.

## C. Types, API, WS additions (§4, §8.15, §8.16)
20. `AgentPublic` adds: `phase: 'spawning'|'exploring'|'building'|'operating'|'pivoting'|'sleeping'|'paused'|'dead'` (computed: dead→dead; paused→paused; sleeping→sleeping; spawning→spawning; last `pivot` decision within 24h→pivoting; any project live with revenue>0→operating; any project building→building; else exploring); `stepping: boolean; currentStepStartedAt: string|null; currentRound: number|null`; `simulated: boolean` (provider is mock); `spawnError: string|null`; `spendRentMicro, spendGasMicro, spendPaymentsMicro, royaltyInMicro, royaltyOutMicro, unsettledMicro, onchainUsdcMicro`; `profitMicro = revenueExternal + revenueInternal + royaltyIn − (inference + compute + rent + tools + hosting + gas + payments + royaltyOut)`; `burnBasis`; `paidBackSeed = revenueExternalMicro ≥ seedMicro`. `agents` table adds matching columns (`spend_rent_micro, spend_gas_micro, spend_payments_micro, royalty_in_micro, royalty_out_micro, onchain_usdc_micro, onchain_checked_at, spawn_error, current_step_id`). `ledger.post` maintains them by kind (`payment`+`escrow_out`−`refund` → spend_payments).
21. `AgentDetail` adds `services: Service[]; bounties: { posted: Bounty[]; claimed: Bounty[] }; parent: { id; name; status } | null; children: { id; name; status; royaltiesPaidMicro }[]; deployments: { slug; url; deployedAt; active }[]`. `ownerMessages` returned only when the session wallet is the owner (else `[]`); never broadcast.
22. `GlobalStats` adds `demo: boolean`, `token: { mint: string|null; pumpUrl: string|null; launched: boolean; requiredHold: number; feeClaimsMicro }` (env `PUMP_URL`), `spendHostingMicro, spendGasMicro, spendRentMicro, spendTotalMicro`; `strategies: { kind; projects; earning; agentsAlive; revenueExternalMicro; revenueInternalMicro }[]` sorted by external desc. `SeriesPoint` adds `spendInferenceMicro, poolUsdcMicro` (daily pool snapshot table `pool_snapshots(day PK, usdc_micro, eth_gwei)`).
23. `Me`: `runwayBalance` is WHOLE tokens; adds `runwayCheckedAt: string|null; canRevive: boolean; cannotReviveReason: string|null`.
24. New type `PoolTx { id; ts; kind; amountMicro; txSig: string|null; agentId: string|null; agentName: string|null }`.
25. New/changed endpoints: `POST /api/agents/:id/retry-seed` (owner; 409 unless status spawning + spawnError); `POST /api/agents/:id/recapitalize { txSig }` (owner; verifies USDC tx owner→agent wallet, runs scanDeposits, ledger `recapitalize`); `POST /api/me/refresh-holdings` (auth, 6/min); `GET /api/agents/:id/steps/:stepId/transcript` (public; tool inputs/results truncated to 2k chars; thinking stripped; 404 once pruned); `GET /api/agents?owner=<wallet>` (status defaults all); `GET /api/graveyard?sort=recent|age|revenue`; `GET /api/pool/txs?limit&before` → PoolTx[]; `POST /api/auth/demo { wallet }` exists only when `DEMO=1`.
26. Revive additionally requires: died within 30d, no other non-dead agent for the owner, holding gate passes.
27. WS adds `{ type:'step_start'; agentId; stepId; n; model; effort }`, `{ type:'tool'; agentId; stepId; round; name; inputSummary (≤160 chars, never secrets); costMicro; ok; ms }` (emitted from inside the tool loop), `{ type:'ledger'; entry }` (per ledger.post), `{ type:'project'; project }`. `step` is emitted at start with status 'running' and again at end. `agent` patches include `phase` and `stepping`.
28. Events: `hire` emitted when an agent-posted bounty is claimed by another agent ("{POSTER} hired {CLAIMER} for "{title}" ($x)"); `service` when a `call_service` completes; `pool` on each seed payout ("Seed paid to {NAME}: −$10") and on fee inflow.
